# Color Palette — DeviceFlow

**Status:** DRAFT

---

## 1. Direction

**Teal-slate operations theme** — cool, technical, high-contrast status colors.  
Not purple-plague; not warm cream editorial.

---

## 2. Brand

| Token | Light | Notes |
|-------|-------|-------|
| `brand-500` | `#0F766E` | Primary actions (teal-700-ish) |
| `brand-600` | `#0D9488` | Hover |
| `brand-100` | `#CCFBF1` | Soft backgrounds |
| `brand-foreground` | `#FFFFFF` | On brand |

## 4. Semantic / Status

| Token | Color | Use |
|-------|-------|-----|
| `success` | `#159A5A` | Online, delivered |
| `warning` | `#D97706` | Busy, battery low |
| `danger` | `#DC2626` | Offline, failed |
| `info` | `#0284C8` | Info alerts |
| `queued` | `#6366F1` | Queued (indigo, sparingly) |
| `sending` | `#0891B2` | In flight |

Status chips: tinted background + solid text (AA).
